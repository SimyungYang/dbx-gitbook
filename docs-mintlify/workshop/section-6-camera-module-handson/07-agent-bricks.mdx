## 개요

3가지 유형의 에이전트를 만들고, 하나의 **Supervisor Agent**로 통합합니다.

| 에이전트 | 역할 | 데이터 소스 | 사용 시나리오 |
|---------|------|-----------|-------------|
| **Knowledge Assistant (KA)** | 제조 SOP·품질기준·설비 트러블슈팅 Q&A | 문서 (Vector Search) | "AA 틸트 규격은?", "리플로우 피크온도 기준은?" |
| **Genie Agent** | 데이터 기반 분석 질의 | Gold 테이블 (Genie Space) | "이번 주 라인2 수율은?", "불량 파레토 Top5는?" |
| **Supervisor Agent** | 위 에이전트 오케스트레이션 | 위 에이전트들 | 질문 의도에 따라 적절한 에이전트로 라우팅 |

**Supervisor 라우팅 규칙**

| 사용자 질문 유형 | 라우팅 대상 | 예시 |
|---------------|-----------|------|
| 규격/기준/사용법/트러블슈팅 | **KA** (문서 기반) | "AA 공정 틸트 허용 규격이 얼마야?" |
| 데이터/통계/추이/비교 | **Genie Agent** (데이터 기반) | "라인2 이번 주 수율 추이는?" |
| 복합 (원인 분석 + 대응) | **KA + Genie 둘 다** | "라인2 MTF 불량이 급증했는데 원인과 대응 방법은?" |

## Part A: Knowledge Assistant (KA) — 제조 지식 챗봇

### 개념

Knowledge Assistant는 **비정형 문서**(SOP, 품질기준서, 설비 매뉴얼)를 Vector Search로 인덱싱하여, 질문에 관련 문서를 찾아 답변하는 RAG 기반 에이전트입니다.

> 💡 **왜 Vector Search인가?** SQL의 `LIKE '%틸트%'`는 정확히 "틸트"가 든 문서만 찾지만, Vector Search는 "광축 정렬 기울기 허용치"처럼 **의미가 비슷한 문서**도 찾아냅니다. 이것이 RAG(관련 문서를 먼저 검색 → LLM이 답변 생성)의 핵심입니다.

### Step 1: 지식 문서 준비

> [06. 비정형 AI 함수](06-ai-functions-unstructured)에서 SOP/매뉴얼 PDF를 파싱해 두었다면 그 결과를 활용합니다. 여기서는 KA용 지식 베이스 테이블을 직접 생성하는 경로를 제공합니다.

#### Genie Code 프롬프트: 제조 지식 베이스 생성

```
카메라 모듈 제조 현장용 지식 베이스 문서를 생성해줘. Delta 테이블로 만들어줘.

테이블: ccm_factory.bronze.mfg_knowledge_base

컬럼:
- doc_id: STRING (고유 문서 ID)
- category: STRING (카테고리)
- title: STRING (제목/질문)
- content: STRING (본문, 500~1500자, 실제 제조 SOP 수준의 상세한 한국어)
- tags: `ARRAY<STRING>` (관련 태그)
- process_stage: STRING (관련 공정: SMT/DISPENSE/REFLOW/ALIGN/AOI/FINAL/COMMON)
- last_updated: DATE

카테고리별 문서 (총 90개):

1. 공정 SOP (20개):
   - SMT 실장 표준 작업 (노즐/피더 셋업, 실장 offset 관리 기준)
   - 디스펜싱 도포량/압력 관리, UV 경화 조건 (LENS_BOND 경화량 규격)
   - 리플로우 프로파일 설정 (존별 온도, 피크온도 240~250°C, TAL 관리)
   - Active Alignment 정렬 절차 (focus/tilt/rotation, MTF 목표)
   - AOI 검사 셋업, 최종 화질검사(MTF/데드픽셀/이물) 판정 기준

2. 품질 기준 (20개):
   - MTF SFR 규격 (모델별 target, 중심/코너 최소치)
   - AA 틸트 허용 규격 (arcmin 기준), focus Z 허용 편차
   - 데드픽셀/이물/얼룩 판정 기준, SNR/왜곡/주변광량비 규격
   - Cpk 공정능력 관리 기준 (1.33 이상), SPC 관리한계

3. 설비 트러블슈팅 (20개):
   - SMT 노즐 잼/픽업불량/인식불량 대응
   - 디스펜서 니들 막힘, 진공 누설 대응
   - 리플로우 온도 편차, 컨베이어 이상 대응
   - AA 장비 정렬 실패(RETRY 반복) 대응
   - 설비 진동/온도 이상 전조 시 점검 절차

4. 불량 대응 (20개):
   - 불량코드별 원인/조치 (PLACEMENT/BONDING/ALIGNMENT/CONTAMINATION/IMAGE_QUALITY)
   - 자재 로트 불량 발생 시 격리/추적 절차
   - REWORK/SCRAP 판정 기준, 8D 리포트 작성 가이드

5. 클린룸/환경 관리 (10개):
   - 클린룸 등급/파티클 관리 기준, 온습도/차압 관리
   - ESD 관리, 파티클 급증 시 대응

Delta 테이블로 저장하고, 실제 제조 현장 SOP 수준의 상세하고 정확한 한국어 콘텐츠로 작성해줘.
```

### Step 2: Vector Search 엔드포인트 생성 (미리 시작)

> ⚠️ Vector Search 엔드포인트/인덱스 생성은 **5~10분** 소요됩니다. KA 생성 전에 먼저 시작하세요.

```
Vector Search 엔드포인트를 만들어줘.
- 이름: vs-endpoint-ccm
- 타입: Managed (Databricks 관리)
상태가 Online이 되면 알려줘.
```

### Step 3: Knowledge Assistant 생성

#### Genie Code 프롬프트 (AI Dev Kit MCP: manage_ka)

```
Knowledge Assistant를 만들어줘.

설정:
- 이름: 카메라 모듈 제조 가이드
- 설명: 카메라 모듈 제조 공정의 SOP, 품질 기준, 설비 트러블슈팅, 불량 대응에 대해 답변합니다.
- 지식 소스: ccm_factory.bronze.mfg_knowledge_base 테이블
  - 임베딩 대상 컬럼: content
  - 메타데이터 컬럼: category, title, tags, process_stage
- Vector Search 엔드포인트: vs-endpoint-ccm
- Vector Search 인덱스: vs-index-mfg-knowledge
- 임베딩 모델: databricks-gte-large-en
- LLM 모델: databricks-claude-sonnet-4 (또는 databricks-meta-llama-3.3-70b-instruct)
- System Prompt:

"당신은 카메라 모듈 제조 공정 전문 어시스턴트입니다.
규칙:
1. 반드시 제공된 지식 문서에 기반하여 답변하세요.
2. 문서에 없는 내용은 '해당 정보를 지식 베이스에서 찾을 수 없습니다'라고 답하세요.
3. 한국어로 답변하되, 기술 용어는 영문 병기 (예: 광축 정렬(Active Alignment), 공정능력(Cpk))
4. 규격/수치를 답할 때는 단위와 관리 기준(상/하한)을 명확히 하세요.
5. 절차가 필요하면 번호 매기기를 사용하세요.
6. 안전/품질 주의사항이 있으면 반드시 언급하세요."

생성 후 테스트 질문 3개를 실행해줘:
1. "Active Alignment 공정에서 틸트 허용 규격은 얼마인가요?"
2. "리플로우 피크 온도 관리 기준을 알려주세요"
3. "SMT 노즐 픽업 불량이 자주 발생할 때 어떻게 대응하나요?"
```

### KA 생성 확인

```
"카메라 모듈 제조 가이드" Knowledge Assistant가 정상 생성됐는지 확인해줘.
Vector Search 엔드포인트 상태와 인덱스 문서 수도 알려줘.
```

> ⚠️ 인덱싱은 **5~10분** 소요됩니다. 인덱스 상태가 "PROVISIONING"이면 "ONLINE"이 될 때까지 기다린 뒤 테스트하세요. 인덱싱 전에 질문하면 "관련 문서를 찾을 수 없습니다"가 나옵니다.

### Step 3: KA 테스트 & 평가

```
"카메라 모듈 제조 가이드" KA에 다음 질문을 보내고 답변 품질을 평가해줘.

평가 기준 (각 1~5점):
- 정확성: 규격/수치가 문서와 일치하는지
- 완전성: 질문에 충분히 답했는지
- 관련성: 검색된 문서가 질문과 관련있는지
- 가독성: 답변이 읽기 쉬운지

테스트 질문 10개:
1. "MTF SFR 중심 규격은 모델마다 어떻게 다른가요?"
2. "데드픽셀 몇 개부터 불량으로 판정하나요?"
3. "디스펜싱 UV 경화량 규격은?"
4. "Cpk 관리 기준은 얼마인가요?"
5. "AA 장비가 RETRY를 반복하면 어떻게 하나요?"
6. "이물(particle) 불량이 발생하면 원인을 어떻게 찾나요?"
7. "리플로우 TAL이란 무엇이고 관리 기준은?"
8. "자재 로트 불량이 확인되면 어떤 절차를 따르나요?"
9. "클린룸 파티클이 급증하면 어떻게 대응하나요?"
10. "8D 리포트는 어떻게 작성하나요?"

각 질문의 4개 점수와 종합 평균을 표로 보여줘.
평균 4점 미만 질문은 mfg_knowledge_base 문서 보강 후보야.
```

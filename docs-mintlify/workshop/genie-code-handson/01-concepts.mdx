모듈 1에서 만나는 Databricks 기능을 한눈에 정리합니다. 각 항목의 상세 사용법은 모듈 본문의 해당 시점에서 다룹니다.

| 개념 / 기능 | 한 줄 요지 |
|------|-----------|
| **합성 / 시드 데이터** | 민감정보 없이 현실 분포를 흉내 낸 가짜 데이터. 강사 시드 임포트 + Genie Code 생성 시연 2트랙 |
| **PySpark** | Spark의 분산 처리 Python API. Serverless에서 pandas 대신 기본으로 290만 건 병렬 생성·적재 |
| **Faker / dbldatagen** | Faker=현실적인 가짜값(이름·날짜·코드) 생성, dbldatagen=분포·상관 제어에 강함(비율·범위 지정 대량 생성) |
| **Delta Lake** | ACID 트랜잭션·Time Travel을 지원하는 기본 테이블 형식. 전 17테이블 저장 형식 |
| **Parquet** | 컬럼 단위 압축 오픈 파일 포맷. Delta 내부 저장 + 시드 데이터 교환 포맷 |
| **COPY INTO / CTAS** | 파일 반복 적재 / 쿼리 결과의 테이블화. 시드 parquet 임포트·공유 카탈로그 복제 |
| **UC Volumes** | UC 거버넌스 아래 파일 저장 영역(`/Volumes/...`). 시드 parquet·비정형 파일 저장 |
| **의도적 데이터 품질 이슈** | 교육 목적으로 심은 결함·상관(중복·단위 오류·규칙 위반 등). 이후 EDA·정제·AI 함수 실습의 재료 |

> MDX 참고: 스키마 표의 `MAP<STRING,STRING>`·`ARRAY<STRING>` 같은 타입은 백틱으로 감싸 표기합니다.

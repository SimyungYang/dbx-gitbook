## Part E: 시계열 · 추세 분석

스냅샷 분포를 넘어 **시간에 따른 변화**를 봅니다. 제조에서는 "언제부터 나빠졌나"가 곧 원인 추적의 출발점입니다.

**1단계 —** 먼저 일별 수율 추세만.

```
@ccm_factory.bronze.final_image_test 로 일자별 최종 수율(PASS 비율)을 계산해서 꺾은선 차트로 보여줘.
```

**2단계 —** 라인 차원과 이동평균 추가.

```
방금 추세를 라인(line_id)별로 나눠서 겹쳐 보여주고, 7일 이동평균선도 같이 그려줘.
```

**3단계 —** 요일·근무조 계절성 확인.

```
요일별·근무조(shift)별 평균 수율과 불량률에 반복되는 패턴이 있는지 봐줘.
NIGHT 조에서 불량률이 오르는 경향이 있는지 특히 확인해줘.
```

> ✅ 특정 라인의 수율이 어느 시점부터 계단식으로 하락하거나, NIGHT 조 불량률이 유의하게 높게 나오면 이후 설비/교대 요인 분석의 단서가 됩니다.

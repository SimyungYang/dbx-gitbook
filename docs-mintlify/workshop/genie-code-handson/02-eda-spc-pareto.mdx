## Part F: 공정능력(SPC) · 파레토 분석

품질 데이터를 **관리 지표**로 바꿔 봅니다. 공정능력(Cpk)과 파레토는 제조 품질의 공용어입니다.

### 공정능력(Cpk) 사전 탐색

**1단계 —** 핵심 파라미터 하나로 시작.

```
@ccm_factory.bronze.active_alignment.mtf_center_pct 에 대해 평균·표준편차와, product_master의 규격(spec_mtf_min)을 기준으로
공정능력지수 Cpk를 모델별로 계산해줘.
```

**2단계 —** 파라미터를 넓히고 경고선.

```
같은 방식으로 tilt_x_arcmin, focus_z_um 의 Cpk도 구하고, Cpk < 1.33 인 (모델×파라미터) 조합을 표시해줘.
```

> 💡 Cpk 1.33 미만은 통상 "공정 개선 필요" 신호입니다. 규격이 없으면 평균±3σ로 관리한계를 잡아도 됩니다.

### 불량 파레토

**1단계 —** 불량코드 상위부터.

```
@ccm_factory.bronze.defect_events 를 defect_code 별로 집계해서 건수 내림차순 파레토 차트로 보여주고, 누적 비율선도 그려줘.
```

**2단계 —** 80/20과 차원 분해.

```
상위 몇 개 불량코드가 전체의 80%를 차지하는지 알려주고, 그 상위 불량들을 라인·모델별로 쪼개서 어디에 몰리는지 보여줘.
```

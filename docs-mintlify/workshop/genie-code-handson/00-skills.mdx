## Skill 설정 — 도메인 지식 자동 로딩

Custom Instructions가 "항상 지킬 규칙"이라면, **Skill**은 Genie Code가 필요할 때 참고하는 **도메인 전문 지식 묶음**입니다. 워크스페이스의 `Workspace/.assistant/skills/` 에 올려두면 Genie Code가 관련 작업에서 **자동으로 로딩**합니다.

| 구분 | Custom Instructions | Skill |
|------|--------------------|-------|
| 성격 | 항상 적용되는 규칙(시스템 프롬프트) | 관련 작업에서만 로딩되는 지식 |
| 위치 | `.assistant_instructions.md` | `Workspace/.assistant/skills/<name>/SKILL.md` |
| 예 | 네이밍·안전·언어 규칙 | 카메라 모듈 공정/스키마/판정기준 지식 |

이 워크샵의 공유 워크스페이스에는 **공식 Databricks Agent Skills**가 강사에 의해 **이미 배포**돼 있습니다([databricks/databricks-agent-skills](https://github.com/databricks/databricks-agent-skills/tree/main/skills)). 별도로 만들 필요 없이, Genie Code가 관련 작업(SDP 파이프라인·대시보드·Vector Search 등)에서 이 스킬을 자동으로 참고합니다. 여기서는 **이미 있는 스킬을 확인하고 활용**해 봅니다.

### Step 1: 배포된 Skill 목록 확인

```
현재 이 워크스페이스에서 사용 가능한 Genie Code Skills 목록과 각 스킬의 용도를 보여줘.
```

> 💡 **화면 참고**: Settings → **Skills** 탭에서도 활성화된 스킬 목록을 볼 수 있습니다. `Workspace/.assistant/skills/` 에 배포된 스킬은 별도 설정 없이 자동 로딩됩니다.

### Step 2: Skill이 실제로 돕는지 체험

특정 작업을 시키면 관련 스킬이 자동 로딩되는지 봅니다.

```
Lakeflow(SDP) 파이프라인을 만들 때 참고할 만한 스킬이 있어? 있으면 그 스킬 기준으로 권장 방식을 요약해줘.
```

### Step 3 (선택): 우리 도메인 Skill 추가

기본 스킬 외에, 카메라 모듈 공정 용어·스키마를 담은 **도메인 스킬**을 추가하면 Genie Code가 우리 현장 맥락(SMT·AA·MTF, `ccm_factory` 테이블 구조)을 더 잘 이해합니다.

```
카메라 모듈 공장 도메인 지식을 담은 Genie Code Skill을 만들어줘.
- 경로: /Workspace/.assistant/skills/ccm-factory/SKILL.md
- name·description frontmatter
- 공정 흐름(SMT→디스펜싱→리플로우→AA→AOI→최종 화질검사)과 핵심 지표(수율·FPY·OEE·MTF·틸트·Cpk) 용어
- ccm_factory bronze/silver/gold 주요 테이블 이름·용도 표
저장 후, 사용 가능한 Skills 목록에서 ccm-factory가 보이는지 확인해줘.
```

> 공식 문서: [Genie Code Skills](https://docs.databricks.com/en/genie-code/skills.html) · 스킬 저장소: [databricks-agent-skills](https://github.com/databricks/databricks-agent-skills)

모듈 4에서 만나는 Databricks 기능과 제조 지표를 한눈에 정리합니다. 각 항목의 상세 사용법은 모듈 본문의 해당 시점에서 다룹니다.

| 개념 / 기능 | 한 줄 요지 |
|------|-----------|
| **AI/BI Dashboards** | UC 테이블을 SQL로 곧바로 시각화하는 대시보드 기능. 수율·품질·OEE 운영 대시보드 3종 제작 |
| **데이터셋 vs 위젯** | 데이터셋=SQL 결과 집합, 위젯=그 결과의 시각 표현. 하나의 데이터셋을 여러 위젯이 공유 |
| **시각화 유형** | 데이터 성격별 최적 차트 선택(비교=막대, 추세=꺾은선, 목표=게이지, 상위집중=파레토). 3D·파이 남발 지양 |
| **필터 & 파라미터** | 보는 범위를 좁히는 컨트롤(날짜·라인·모델·근무조). 데이터셋의 `WHERE`에 자동 반영 |
| **Databricks Apps 배포** | 대시보드를 독립 웹 앱으로 감싸 URL로 공유. 서버·인증·호스팅은 플랫폼이 관리 |
| **제조 지표** | 수율·FPY·OEE·Cpk 등 핵심 KPI. 모듈 3의 Gold 집계 테이블을 소비해 라인 상태를 즉시 판단 |

> 시각화 매핑 예: 수율/OEE=게이지+추이 꺾은선, 불량 코드=파레토, Cpk·설비 건강=히트맵, 구성비=도넛/Stacked Bar.

공식 문서: [AI/BI Dashboards](https://docs.databricks.com/en/dashboards/index.html)

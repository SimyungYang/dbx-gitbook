## Part G: 택트타임 · 설비가동(OEE) 사전 탐색

생산성 관점입니다. 이후 Gold의 OEE·사이클타임 집계로 이어집니다.

### 스테이션 택트타임 & 병목

**1단계 —** 스테이션별 사이클타임 분포.

```
@ccm_factory.bronze.production_events 의 cycle_time_sec 을 station 별로 분포(중앙값·p95)와 함께 보여줘.
```

**2단계 —** 병목 탐색.

```
라인별로 어느 station 의 사이클타임이 가장 길어 병목인지 찾아주고, 시간대별로 병목이 바뀌는지도 봐줘.
```

### 설비 가동/비가동 구조

**1단계 —** 다운타임 구성.

```
@ccm_factory.bronze.equipment_downtime 를 downtime_type(BREAKDOWN/PM/CHANGEOVER/IDLE)별 총 시간·건수로 집계해서 보여줘.
```

**2단계 —** 가용성과 MTBF/MTTR 근사.

```
설비별 총 비가동시간으로 가용성(Availability)을 근사하고, BREAKDOWN 기준 MTBF·MTTR도 대략 계산해줘.
가용성이 낮은 설비 상위 10대를 보여줘.
```

> ✅ 특정 설비의 BREAKDOWN 시간이 두드러지면, Part D의 온도·진동 추세 분석과 연결해 예측정비 후보로 삼을 수 있습니다.

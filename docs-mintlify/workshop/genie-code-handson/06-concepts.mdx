모듈 6에서 만나는 SQL AI 함수와 비정형 처리 개념을 한눈에 정리합니다. 각 항목의 상세 사용법은 모듈 본문의 해당 시점에서 다룹니다.

| 개념 / 기능 | 한 줄 요지 |
|------|-----------|
| **Databricks Document Intelligence** | SQL로 LLM을 부르는 내장 AI 함수 브랜드(배포·엔드포인트 관리 불필요). 비정형 데이터를 SQL만으로 정형화 |
| **`ai_classify`** | 텍스트를 정해진 레이블 집합으로 자동 분류. 필드 리턴 증상 → 근본원인 카테고리 태깅 |
| **`ai_extract`** | 텍스트에서 지정 항목을 구조화 추출. 증상/불량부위/의심원인 컬럼 분리 |
| **`ai_summarize` / `ai_gen`** | 긴 텍스트 요약 / 자유형 생성. 모델별 리턴 증상을 간결히 요약(길이는 단어 수 인자로 제어) |
| **`ai_parse_document`** | PDF·문서를 텍스트·구조로 파싱. 8D 리포트 PDF의 지식을 데이터화 |
| **`ai_query` (Vision LLM)** | 임의 서빙 엔드포인트·이미지를 SQL에서 직접 호출. AOI 불량 이미지 분류·설명 |
| **Agent Bricks Foundation Model API** | AI 함수가 호출하는 관리형 모델 엔드포인트(Claude·GTE 등). 배포 없이 최신 모델 사용 |
| **배치 추론 / AI Ready Data** | 검증한 로직을 전체에 적용해 만든 정형 인사이트 테이블. 대시보드·Genie·RAG의 소스 |

> AI 함수는 엔드포인트 호출당 과금됩니다. 반드시 `LIMIT 10~20`으로 결과·비용을 확인한 뒤 전체에 적용하고, 민감 텍스트는 마스킹 후 처리합니다.

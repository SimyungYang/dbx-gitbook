## 데이터 생성 후 종합 검증

각 테이블을 만들 때마다 `방금 만든 테이블의 row 수와 주요 컬럼 분포를 확인해줘.` 로 간단히 확인하고, 17개를 다 만든 뒤 아래 종합 검증을 실행합니다.

```
ccm_factory.bronze 스키마의 모든 테이블에 대해 확인해줘:
1. 각 테이블 row count
2. serial_id / equipment_id / material_lot_id 의 참조 무결성 (마스터에 없는 값 건수)
3. timestamp 범위가 2025년 위주인지
4. 의도적으로 심은 이슈가 실제로 존재하는지:
   - ccm_factory.bronze.active_alignment.mtf_center_pct > 100 건수
   - ccm_factory.bronze.equipment_sensor_logs.temperature_c > 200 건수
   - ccm_factory.bronze.final_image_test.snr_db NULL 비율
   - ccm_factory.bronze.production_events 중복(serial+timestamp) 건수
결과를 데이터 품질 요약 표로 보여줘.
```

> 💡 **AI 결과에 도전하기**: 확인에 만족하지 말고 교차검증을 시켜보세요 —
> ```
> active_alignment의 aa_result=FAIL 레코드가 실제로 MTF 낮거나 tilt 큰 조건과 일치하는지,
> 내가 요청한 규칙대로 만들어졌는지 검증하고 불일치가 있으면 알려줘.
> ```

|--------|------|-----------|

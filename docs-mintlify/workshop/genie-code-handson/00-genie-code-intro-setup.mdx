### 이 모듈의 목적

이후 모든 실습(데이터 생성·EDA·파이프라인·대시보드·에이전트)은 데이터를 담을 공간인 **Unity Catalog**와, 그 공간을 이해하는 코딩 AI인 **Genie Code**가 준비되어 있어야 시작할 수 있습니다. 그래서 모듈 0에서 환경과 Genie Code 설정을 **가장 먼저** 끝냅니다.

**모듈 0에서 만드는 Unity Catalog 오브젝트**

| 오브젝트 | 이름 | 용도 |
|---------|------|------|
| 카탈로그 | `ccm_factory` | 이 워크샵의 최상위 데이터 네임스페이스 |
| 스키마 4개 | `bronze` / `silver` / `gold` / `quarantine` | 메달리온 계층 + 품질 격리 |
| 볼륨 | `bronze.raw_files` | PDF·이미지·zip 등 비정형 파일 저장 |

> **핵심 메시지**: "Genie Code는 Databricks를 아는 코딩 AI다. 코드를 직접 안 써도 되지만, **실행 승인은 사람이 쥔다.**"

## Part A: Genie Code란?

일반 코딩 AI(ChatGPT/Copilot)와의 결정적 차이는 **Databricks 환경을 직접 안다**는 점입니다.

| | ChatGPT / Copilot | **Genie Code** |
|---|---|---|
| 테이블 스키마 | 사용자가 알려줘야 | **Unity Catalog에서 자동 읽음** |
| 코드 실행 | 생성만 | **직접 실행 + 결과 확인 + 에러 자동 수정** |
| 데이터 탐색 | 불가 | **테이블 검색·샘플 조회·프로파일링** |
| 작업 범위 | 코드 조각 | **계획→실행→검증→수정 자동 반복** |
| 환각 | 컬럼명 지어냄 | **실제 메타데이터 기반, 환각 최소화** |

### 어디서 쓰나 — 6개 제품 영역

노트북 · SQL Editor · AI/BI 대시보드 · Lakeflow Pipeline Editor · MLflow · Jobs. 각 화면 우측 상단 **✨ 아이콘** 또는 `Cmd+I`로 사이드 패널을 엽니다.

### 동작 방식 & 노력(Effort) 설정

Genie Code는 **계획 → 코드 → 실행 → 검증 → 에러 수정**을 자율로 수행하는 에이전트입니다. (과거의 "Agent/Chat 모드" 선택은 없어졌고, 지금은 항상 이 방식으로 동작합니다.) 실행 전에는 **승인**(Allow)을 요청하므로 통제권은 사람이 쥡니다.

대신 **노력(Effort)** 설정으로 품질과 비용을 조절합니다 (Genie Code 패널 하단 드롭다운):

| 노력(Effort) | 의미 | 언제 |
|---|---|---|
| **자동 (권장)** | 모든 태스크에서 최고 품질 | 기본값 — **이 워크샵 권장** |
| **낮음** | 간단한 태스크에 대한 비용 절감 | 단순 조회·반복 작업 |

> 이 핸즈온은 노력(Effort)을 **자동**(권장)으로 진행합니다.

### 비용 구조 (한 줄 요약)

- **Genie Code 사용은 과금됩니다** — 소비량 기반(consumption). 정확한 요율은 공식 가격 정책을 확인하세요.
- **두 축의 비용**: ① Genie Code 사용(프롬프트 → 계획·코드/쿼리 생성) + ② 생성된 코드/쿼리를 돌리는 **컴퓨트** 비용
- **절감 팁**: 개발·테스트 중 `LIMIT 1000` 습관화, 불필요한 대용량·반복 실행 지양
- 데이터 보호는 유지 — 사용자 데이터로 모델을 학습하지 않음(Zero Data Retention). *과금 여부와는 별개.*

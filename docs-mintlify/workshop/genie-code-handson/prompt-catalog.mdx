이 페이지는 모듈 0~7에 나오는 **모든 Genie Code 프롬프트**를 용도별로 한곳에 모은 치트시트입니다. 실습 중 필요한 프롬프트를 여기서 바로 복사해 쓰세요. 각 프롬프트에는 출처 모듈과 실행 방식 배지를 붙였습니다.

## 표기 범례

| 배지 | 의미 |
|------|------|
| 🟢 **네이티브** | Genie Code 기본 기능만으로 실행 — SQL·데이터 조회·CTAS·AI 함수 등 |
| 🔵 **UI** | 크로스 프로덕트 생성 — 각 제품 UI(Genie · Dashboards · Agent Bricks · Lakeflow)에서 생성 |

> 대부분의 작업은 🟢 네이티브로 실행되고, 🔵는 각 제품 UI에서 만듭니다. 프롬프트는 필요에 맞게 표(테이블명·수치)를 바꿔 재사용하세요.

## 1. 환경 설정 · 사전점검

**워크샵 사전 확인** 🟢 — 모듈 0 · Part C
```
내 Databricks 개발 환경이 준비됐는지 점검해줘:
1. 지금 Serverless 컴퓨트에 연결되어 있는지, Python/SQL 실행이 되는지 간단히 테스트
2. 내가 접근 가능한 카탈로그 목록 (SHOW CATALOGS)
3. %pip install faker 가 되는지 (pyspark 관련 패키지는 테스트하지 마)
4. 현재 워크스페이스 리전과, AI 기능(Genie Code)이 활성 상태인지
결과를 표로 요약해줘.
```

**Custom Instructions 적용 확인** 🟢 — 모듈 0 · Part E
```
Custom Instructions가 적용됐는지 테스트해줘.
ccm_factory.bronze 스키마에 test_table 이름으로 1행짜리 Delta 테이블을 만들고 바로 삭제해줘.
권한·컴퓨트가 정상인지 확인용이야.
```

## 2. 카탈로그 · 스키마 · 볼륨 (Unity Catalog)

**UC 환경 설정** 🟢 — 모듈 0 · Part D
```
Unity Catalog에 다음 환경을 설정해줘 (기존 오브젝트가 있으면 DROP하지 말고 스킵):

- 카탈로그: ccm_factory
- 스키마: bronze, silver, gold, quarantine
- 볼륨: bronze 스키마에 raw_files 볼륨 (PDF/이미지 등 비정형 저장용)

각 스키마에 COMMENT:
- bronze: 'Raw 제조/공정/검사/설비 텔레메트리'
- silver: '정제·표준화된 데이터'
- gold: '수율·불량·OEE 등 비즈니스 집계'
- quarantine: '데이터 품질 위반 격리'
```

**스키마/COMMENT 확인** 🟢 — 모듈 0 · Part D
```
ccm_factory 카탈로그의 모든 스키마와 COMMENT를 보여줘.
```

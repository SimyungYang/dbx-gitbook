### 테이블 11: equipment_sensor_logs (설비 센서 1분 텔레메트리)

> 예측정비(PdM)용. 온도·진동·진공·전류.

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `equipment_id`·`timestamp` | | 기본 |
| `temperature_c` | DOUBLE | 설비 온도 |
| `vibration_mm_s` | DOUBLE | 진동 |
| `vacuum_kpa` | DOUBLE | 진공(픽업/본딩) |
| `motor_current_a` | DOUBLE | 모터 전류 |
| `air_pressure_kpa` | DOUBLE | 공압 |

**1단계 —** 먼저 뼈대만.
```
설비 센서 텔레메트리 테이블 ccm_factory.bronze.equipment_sensor_logs 를 만들려고 해. 컬럼 구성을 먼저 제안해줘.
```
**2단계 —** 건수와 샘플링·주기를 지정.
```
300,000건 생성해줘. equipment_id는 equipment_master에서 샘플링(활성 설비), 1분 간격으로.
```
**3단계 —** 센서 값 분포를 추가.
```
temperature_c는 정상 25~45(노후 설비는 서서히 상승 추세), vibration_mm_s는 정상 0.5~3.0(고장 전조 설비는 5 이상 스파이크), vacuum_kpa는 -80~-60(음압), motor_current_a는 2~8.
```
**4단계 —** 의도적 이슈와 저장.
```
[의도적 이슈] 약 0.2%는 temperature_c > 200 (센서 스파이크 이상치)으로 넣어줘. Delta로 저장, COMMENT 추가.
```

| 컬럼 | 타입 | 설명 |

**1단계 —** 먼저 뼈대만.
```
최종 화질검사 테이블 ccm_factory.bronze.final_image_test 를 만들려고 해. 컬럼 구성을 먼저 제안해줘.

```
250,000건 생성해줘. serial_id는 FINAL 스테이션 통과 시리얼, model_code 조인으로 spec을 참조해줘.
```
**3단계 —** 화질 지표 값을 추가.
```
mtf_sfr_center는 PASS 75~92 / FAIL 55~72, corner는 center-10 내외. dead_pixel_count는 대부분 0~2(불량은 3 이상), particle_count/blemish_count는 대부분 0~1(이물 불량은 5 이상). snr_db는 34~42, distortion_pct는 -2~2, relative_illumination_pct는 45~65.

**4단계 —** 판정 규칙을 추가.
```

**5단계 —** 의도적 이슈와 저장.
```

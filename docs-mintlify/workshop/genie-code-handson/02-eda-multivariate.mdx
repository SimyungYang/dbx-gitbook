## Part I: 다변량 · 세그먼트 분석

여러 변수를 **동시에** 봅니다. 개별 상관을 넘어 전체 구조와 세그먼트 차이를 파악합니다.

### 공정 파라미터 상관 히트맵

```
@ccm_factory.bronze.active_alignment 와 @ccm_factory.bronze.final_image_test 를 serial 기준으로 조인해서
주요 수치형 파라미터(mtf_center/corner, tilt_x/y, focus_z, snr_db, distortion_pct) 간 상관행렬을 구하고
히트맵으로 보여줘. 강하게 상관된 쌍을 알려줘.
```

### 모델·고객 세그먼트 & 필드 리턴

**1단계 —** 세그먼트별 수율.

```
모델(model_code)·고객(customer)·module_type(AF/OIS/ToF) 세그먼트별로 최종 수율과 주요 불량 유형을 비교해줘.
```

**2단계 —** 공장 품질 ↔ 필드 리턴 연결.

```
@ccm_factory.bronze.field_returns 의 모델별 리턴율과, 같은 모델의 공장 내 불량률/수율을 나란히 비교해줘.
공장에서 못 걸러 필드로 나간 것으로 의심되는 모델이 있는지 봐줘.
```

> 💡 **AI 결과에 도전하기**: 세그먼트 차이가 보이면 표본 수 차이로 인한 착시가 아닌지 되물어보세요 —
> ```
> 방금 세그먼트별 수율 차이가 표본 수가 적은 모델의 노이즈는 아닌지, 신뢰구간이나 최소 표본 기준으로 다시 검증해줘.
> ```

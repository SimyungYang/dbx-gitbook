### 목적 & 다루는 테이블

- **목적** — 대시보드가 미리 답을 정해 두지 못하는 **즉석 질문**을 자연어로 물어 SQL 없이 답하게 하고, 그 정확도를 튜닝으로 끌어올립니다.
- **다루는 테이블** — 모듈 3에서 만든 Gold 테이블(수율·품질·설비) + 필요한 Bronze 마스터(`product_master`·`equipment_master`·`material_lot_master` 등).
  - 스페이스별로 어떤 테이블을 담는지는 아래 [Part A](#part-a-genie-space-3개-생성)의 각 Space 포함 테이블을 참조하세요.

### 이 모듈에서 사용하는 Databricks 기능

| 기능 | 설명 | 공식 문서 |
|------|------|----------|
| **Genie Space** | 비개발자가 **자연어로 질문**하면 AI가 SQL을 생성해 답하는 공간(NL2SQL). 테이블·비즈니스 용어·샘플 질문을 가르치면 정확도가 오른다. | [docs](https://docs.databricks.com/en/genie/index.html) |
| **Genie Agent** | 여러 Genie Space를 **도구로 묶은** 데이터 분석 에이전트. 질문 의도에 맞는 Space를 골라 답한다. | [docs](https://docs.databricks.com/en/generative-ai/agent-bricks/index.html) |
| **AI Dev Kit MCP** | Genie Code에서 `manage_genie`로 Genie Space를 **자연어로 생성·관리**. | [GitHub](https://github.com/databricks-solutions/ai-dev-kit) |

## 개요

Gold 테이블을 기반으로:
1. **Genie Space 3개**: 생산·수율 / 품질·불량 / 설비·OEE 분석 공간
2. **정확도 고도화** ⭐: 컬럼 COMMENT, 샘플 질문, General Instructions, Joins로 SQL 생성 정확도를 끌어올린다
3. **Genie Agent**: 3개 Space를 하나의 분석 에이전트로 통합

> ⚠️ Genie Space는 **최대 30테이블**(GCP 25). 스페이스별로 관련 Gold + 필요한 마스터만 담습니다.

## Part A: Genie Space 3개 생성

> 💡 `manage_genie` MCP 도구가 필요합니다. 실패하면 사이드바 **Genie → + New**로 UI에서 만들 수 있습니다.

### Genie Space 1: 생산·수율 분석

**1단계 —** 뼈대부터 만든다.
```
'생산·수율 분석' Genie Space를 하나 만들어줘.
```

**2단계 —** 설명을 붙인다.
```
설명은 "카메라 모듈 라인의 생산 실적, 수율, 직행률(FPY), 택트타임을 자연어로 분석합니다." 로 넣어줘.
```

**3단계 —** 포함 테이블을 지정한다.
```
포함 테이블은 아래 5개로 해줘.
- @ccm_factory.gold.daily_yield_summary
- @ccm_factory.gold.first_pass_yield
- @ccm_factory.gold.station_cycle_time
- @ccm_factory.bronze.product_master
- @ccm_factory.bronze.equipment_master
```

**4단계 —** General Instructions를 추가한다.
```
General Instructions에 아래를 넣어줘.
- 수율(yield)은 % 단위, 소수점 1자리로 표시
- 날짜 필터가 없으면 최근 7일 기준
- 라인은 LINE_1~LINE_6, 모델은 model_code로 식별
- 결과가 10행 이상이면 Top 10으로 제한하고 "전체 N건 중 Top 10" 표시
- 고객명은 익명(Global_A/B/C, Domestic_D)이므로 그대로 사용
```

### Genie Space 2: 품질·불량 분석

**1단계 —** 뼈대부터 만든다.
```
'품질·불량 분석' Genie Space를 하나 만들어줘.
```

**2단계 —** 설명을 붙인다.
```
설명은 "불량 파레토, 자재 로트별 불량 상관, AA(Active Alignment) MTF 품질, 공정능력(Cpk)을 분석합니다." 로 넣어줘.
```

**3단계 —** 포함 테이블을 지정한다.
```
포함 테이블은 아래 6개로 해줘.
- @ccm_factory.gold.defect_pareto
- @ccm_factory.gold.material_defect_correlation
- @ccm_factory.gold.aa_quality_trend
- @ccm_factory.gold.spc_process_capability
- @ccm_factory.silver.final_test_clean
- @ccm_factory.bronze.material_lot_master
```

**4단계 —** General Instructions를 추가한다.
```
General Instructions에 아래를 넣어줘.
- 불량률은 % 단위, MTF는 pct 단위(0~100)
- "규격 미달"은 mtf_center < 모델의 spec_mtf_min 기준
- Cpk는 소수점 2자리, "공정능력 부족"은 Cpk < 1.33
- 자재 공급사는 Sup_S1~S8로 식별
- 날짜 미지정 시 최근 7일
```

### Genie Space 3: 설비·OEE 분석

**1단계 —** 뼈대부터 만든다.
```
'설비·OEE 분석' Genie Space를 하나 만들어줘.
```

**2단계 —** 설명을 붙인다.
```
설명은 "설비별 OEE(종합설비효율), 설비 건강 점수, 비가동(downtime)을 분석합니다." 로 넣어줘.
```

**3단계 —** 포함 테이블을 지정한다.
```
포함 테이블은 아래 4개로 해줘.
- @ccm_factory.gold.oee_by_equipment
- @ccm_factory.gold.equipment_health_score
- @ccm_factory.bronze.equipment_downtime
- @ccm_factory.bronze.equipment_master
```

**4단계 —** General Instructions를 추가한다.
```
General Instructions에 아래를 넣어줘.
- OEE = 가용성 × 성능 × 품질, % 단위 소수점 1자리
- "문제 설비"는 OEE < 75% 또는 health_score < 60
- downtime은 분(min) 단위, 유형은 BREAKDOWN/PM/CHANGEOVER/IDLE
- 설비는 equipment_id로 식별, 라인/유형 질문 시 @ccm_factory.bronze.equipment_master 조인
```

### 생성 확인 & 첫 테스트

```
방금 만든 "생산·수율 분석" Genie Space에 테스트 질문을 해줘:
"최근 7일간 수율이 가장 낮은 라인 Top 3는?"
SQL이 정상 생성되고 결과가 나오는지 확인해줘.
```

## Part D: 상관 & 인사이트 탐색

단일 테이블을 넘어 **관계**를 봅니다. 여기서 나온 가설이 이후 Genie·ML의 소재가 됩니다.

### 자재 로트 ↔ 불량 상관

```
특정 자재 공급사/로트가 불량과 상관있는지 분석해줘:
- traceability 로 시리얼별 사용 자재 로트(material_lot_ids)를 펼치고, defect_events / final_image_test 의 불량과 조인
- 공급사(supplier)별 불량률을 계산하고, 평균 대비 유의하게 높은 공급사를 찾아줘
- material_lot_master.defect_rate_incoming(수입검사 불량률)과 실제 생산 불량률의 상관도 봐줘
결과를 공급사별 불량률 막대 차트로 보여줘.
```

> ✅ `Sup_S7`, `Sup_S8`의 불량률이 평균의 2~3배로 나오면 데이터의 의도된 상관이 잘 살아있는 것입니다.

### 설비 상태 ↔ 고장(비가동) 상관

```
설비 노후/이상 신호가 고장으로 이어지는지 분석해줘:
- equipment_sensor_logs 에서 설비별 temperature_c, vibration_mm_s 의 일별 추세를 계산
- equipment_downtime 에서 downtime_type='BREAKDOWN' 발생 설비/시점과 비교
- BREAKDOWN 직전 구간에서 온도/진동이 상승 추세였는지 확인
온도·진동 추세와 고장 시점을 같이 볼 수 있는 시각화를 만들어줘.
```

### 클린룸 환경 ↔ 오염 불량 시간 상관

```
클린룸 파티클 급증이 오염 불량과 시간적으로 연관되는지 분석해줘:
- cleanroom_environment 의 particle_0_3um 이 급증한 라인×시간대를 찾고
- 같은 라인×시간대의 defect_events 중 defect_category='CONTAMINATION' 건수와 비교
- 파티클 스파이크 이후 일정 시간 내 오염 불량이 증가하는 패턴이 있는지 확인해줘
```

### AA 공정 ↔ 최종 화질 결과 연계

```
Active Alignment 품질이 최종 화질 판정으로 이어지는지 검증해줘:
- active_alignment.mtf_center_pct, tilt_x/y_arcmin 과 final_image_test.test_result 를 serial 기준 조인
- AA 단계 MTF가 낮거나 tilt가 큰 시리얼이 최종에서 FAIL 되는 비율이 높은지 확인
- tilt 절대값 구간별 최종 FAIL률을 표로 보여줘
```

> 💡 **AI 결과에 도전하기**: 상관을 봤다면 인과를 단정하지 말고 되물어보세요 —
> ```
> 방금 나온 "Sup_S8 로트의 불량률이 높다"는 결과가, 특정 모델이나 특정 라인에 몰려서 생긴 착시는 아닌지
> 모델·라인을 통제해서 다시 검증해줘. 교란 요인이 있으면 알려줘.
> ```

> 💡 **또 하나의 도전**: 데이터셋 전체에서 흥미로운 인사이트 3가지를 스스로 뽑게 해보세요 —
> ```
> ccm_factory.bronze 전체를 살펴보고, 품질/수율 개선에 도움될 흥미로운 인사이트 3가지를 근거 쿼리와 함께 제시해줘.
> ```

## Part E: EDA → Silver 변환 규칙 도출

EDA에서 찾은 문제를 다음 모듈의 **정제 규칙**으로 정리합니다. 이 표가 [03. 파이프라인](03-transformation-pipeline)의 입력이 됩니다.

```
지금까지의 EDA 결과를 종합해서, Bronze → Silver 변환 규칙을 표로 정리해줘.
컬럼: 대상 테이블 | 발견한 이슈 | 처리 방법(제거/보정/플래그/격리) | 근거
```

### 예상 정리 결과 (참고)

| 대상 테이블 | 발견한 이슈 | 처리 방법 | 근거 |
|------------|-----------|----------|------|
| production_events | (serial, timestamp) 중복 | 최신 1건만 유지(DEDUP) | 택트타임·처리량 과집계 방지 |
| production_events | OUT < IN 시간 역전 | 해당 쌍 제거 | 음수 체류시간 방지 |
| active_alignment | mtf_center_pct > 100 | 클리핑 또는 NULL 처리 | 물리적으로 불가능한 값 |
| equipment_sensor_logs | temperature_c > 200 | 이상치 NULL/필터 | 센서 스파이크 |
| smt_placement_logs | offset 단위 혼입(mm/um) | 단위 표준화(µm) | 부호/스케일 왜곡 |
| final_image_test | snr_db NULL(구형 테스터) | 결측 플래그 + 분석 시 제외 | 평균 왜곡 방지 |
| dispensing_process | LENS_BOND인데 uv_dose_mj NULL | 잠재 불량 플래그로 격리 | 경화 부족 추적 |
| aoi_inspection | defect_flag=false인데 defect_type 존재 | 규칙 위반 격리(quarantine) | 불량 통계 왜곡 |
| 전 테이블 | 마스터에 없는 equipment_id/material_lot_id | quarantine 스키마로 분리 | 조인 손실·집계 오류 방지 |

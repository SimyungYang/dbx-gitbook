모듈 5에서 만나는 Genie 구성 요소와 정확도 튜닝 요소를 한눈에 정리합니다. 각 항목의 상세 사용법은 모듈 본문의 해당 시점에서 다룹니다.

| 개념 / 기능 | 한 줄 요지 |
|------|-----------|
| **Genie / Genie Spaces** | 자연어 질문을 SQL로 답하는 대화형 분석 공간(Space당 최대 30테이블, GCP 25). 생산·수율 / 품질·불량 / 설비·OEE 3개 Space |
| **NL2SQL 원리** | 스키마·COMMENT·샘플·지침을 컨텍스트로 LLM이 SQL 생성. 컨텍스트 품질이 곧 정확도 |
| **테이블/컬럼 COMMENT** | 값의 의미·단위·범위를 다는 한국어 설명. 정확도 영향이 가장 큰 요소 중 하나 |
| **Curated Questions** | 검증된 질문+정답 SQL 샘플 등록. 정확도를 가장 크게 올리는 방법 |
| **General Instructions** | Space 전체의 용어·계산·출력 규칙. 임의 정의 방지 규칙이 핵심(변경 후 New Chat 필요) |
| **Joins & SQL Expressions** | 조인 경로 정의 + 재사용 로직 등록. 다중 테이블 질문의 정확도 확보 |
| **Genie Agent** | 여러 Space를 도구로 묶어 자동 라우팅하는 상위 분석 에이전트. 3개 Space를 하나의 분석가로 통합 |
| **Benchmarks** | 생성 SQL vs 정답 SQL 자동 평가. 튜닝 전후 정확도를 정량 추적 |

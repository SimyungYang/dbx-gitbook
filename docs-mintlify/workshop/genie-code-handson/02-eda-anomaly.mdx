## Part H: 이상탐지 · 결측 메커니즘 심화

품질 진단(Part C)을 **통계적 이상탐지**와 **결측 원인 분석**으로 한 단계 더 파고듭니다.

### 통계적 이상치 탐지

**1단계 —** 설비 텔레메트리 이상 후보.

```
equipment_sensor_logs 의 temperature_c, vibration_mm_s 에 대해 설비별로 Z-score(또는 IQR)를 계산해서
이상치 후보 건수를 설비별로 보여줘. 명백한 센서 스파이크(200℃ 초과)와, 통계적으로만 튀는 값을 구분해줘.
```

**2단계 —** 파라미터 결합 이상.

```
active_alignment 에서 mtf 는 정상인데 tilt 가 큰 것처럼, 단일 컬럼으로는 안 걸리지만
조합으로 보면 이상한 시리얼이 있는지 찾아줘.
```

### 결측 메커니즘 분석

```
final_image_test.snr_db 와 dispensing_process.uv_dose_mj 의 결측이 무작위인지(MCAR),
특정 조건(구형 테스터 설비, 특정 공정타입, 특정 기간)에 몰려있는지(MAR) 분석해줘.
결측이 어떤 그룹에 집중되는지 표로 보여줘.
```

> 💡 결측이 "무작위"가 아니라 특정 설비/공정에 몰려 있으면, 단순 제거는 편향을 만듭니다 — 플래그 후 분석에서 제외하는 편이 안전합니다.

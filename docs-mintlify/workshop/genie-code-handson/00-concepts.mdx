모듈 0에서 만나는 Databricks 기능을 한눈에 정리합니다. 각 항목의 상세 사용법은 모듈 본문의 해당 시점에서 다룹니다.

| 개념 / 기능 | 한 줄 요지 |
|------|-----------|
| **Genie Code** | Databricks 내장 AI 코딩 어시스턴트 — UC 메타데이터를 읽어 코드·쿼리를 생성·실행·수정. 전 모듈의 실습 도구 |
| **노력(Effort)** | Genie Code는 계획→실행→검증을 자율 수행(실행 전 승인). 노력 설정으로 품질↔비용 조절(자동=최고 품질, 낮음=비용 절감) |
| **Unity Catalog** | 카탈로그·스키마·볼륨 3단 데이터 거버넌스. `ccm_factory` 카탈로그에 bronze·silver·gold·quarantine 스키마 구성 |
| **Serverless Compute** | 클러스터 관리 없는 관리형 컴퓨트. 모든 코드·쿼리 실행 기반(R·Scala·mount 등 제약 있음) |
| **Custom Instructions** | 매 대화에 자동 적용되는 시스템 프롬프트. 한국어·PySpark·snake_case·안전 규칙을 고정 |
| **Skill** | 관련 작업에서만 자동 로딩되는 도메인 지식 묶음(`SKILL.md`). 카메라 모듈 공정 지식을 주입 |

> 비용은 소비량 기반. Genie Code 사용과 생성 코드를 돌리는 컴퓨트 두 축에서 과금됩니다.

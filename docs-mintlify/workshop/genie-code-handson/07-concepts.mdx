모듈 7에서 만나는 에이전트·검색 기능을 한눈에 정리합니다. 각 항목의 상세 사용법은 모듈 본문의 해당 시점에서 다룹니다.

| 개념 / 기능 | 한 줄 요지 |
|------|-----------|
| **Agent Bricks** | 코드 없이 UI/API로 에이전트를 만드는 플랫폼(KA·Genie·Supervisor). 세 종류를 프롬프트로 생성 |
| **Vector Search** | 텍스트를 임베딩해 의미가 비슷한 문서를 찾는 검색 엔진. KA의 문서 검색 백엔드(엔드포인트+인덱스 5~10분 소요) |
| **RAG** | 관련 문서를 먼저 검색해 그 근거로 답을 생성하는 방식. 근거 기반 답변으로 환각 억제 |
| **Knowledge Assistant (KA)** | 비정형 문서를 Vector Search로 인덱싱해 답하는 RAG 챗봇. 제조 SOP·품질기준 Q&A |
| **Genie Agent** | 모듈 5의 Genie Space를 도구로 삼아 NL2SQL로 답하는 에이전트. 수율·불량·OEE 데이터 질의 |
| **Supervisor Agent** | 질문 의도를 파악해 하위 에이전트로 라우팅하는 상위 에이전트. 문서+데이터 질문 통합 창구 |
| **Databricks Model Serving** | LLM·임베딩 모델을 API 엔드포인트로 서빙. 에이전트의 추론·임베딩 엔진 |
| **Lakebase** | 내장 PostgreSQL 호환 OLTP DB(선택). 대화 이력·피드백 저장 |
| **MLflow on Databricks** | 에이전트 응답 트레이싱·품질 평가. 라우팅·답변 품질 모니터링 |

## 개요

[모듈 3](03-transformation-pipeline)에서 만든 **Gold 테이블 10개**를 소비하여, 카메라 모듈 공장의 세 이해관계자가 매일 확인하는 대시보드를 만듭니다.

| 대시보드 | 대상 | 핵심 Gold 테이블 |
|----------|------|-----------------|
| **생산/수율 운영** | 생산기술·라인 운영팀 | `daily_yield_summary`, `first_pass_yield`, `station_cycle_time` |
| **품질/불량 분석** | 품질(QA)·공정기술팀 | `defect_pareto`, `material_defect_correlation`, `aa_quality_trend`, `spc_process_capability` |
| **설비 운영/OEE** | 설비보전·제조운영팀 | `oee_by_equipment`, `equipment_health_score` |

> **Tip**: 대시보드 생성은 `manage_dashboard` MCP 도구를 사용합니다. 무거운 도구이니 시작 전 `현재 사용자 정보 알려줘`로 MCP 앱을 깨워두세요. 코드/위젯 생성 시 **Plan 확인 → "Allow in this thread"** (Always Allow 금지).

## Part A: 생산/수율 운영 대시보드

> 라인·모델별 수율과 직행률(FPY), 택트타임을 한눈에 보는 운영 현황판.

### Genie Code 프롬프트

> 한 번에 12개 위젯을 요구하지 말고, 뼈대부터 만들고 위젯을 한 단계씩 덧붙입니다.

**1단계 —** 대시보드 뼈대 + 첫 추이 위젯.

```
gold.daily_yield_summary, gold.first_pass_yield, gold.station_cycle_time 테이블로 "생산/수율 운영 대시보드"를 AI/BI 대시보드로 새로 만들어줘. 우선 일별 수율 추이 꺾은선(최근 30일, 라인별 색상 구분) 하나만.
```

**2단계 —** 맨 위에 KPI 카운터 4개 추가.

```
맨 위에 KPI 카운터 4개를 추가해줘: 오늘 총 생산 수량(합계), 전체 수율 %(양품/투입, 게이지), 직행률(FPY) %(게이지), 활성 라인 수(오늘 실적 있는 라인).
```

**3단계 —** FPY 추이 + 분포 막대 3개 추가.

```
일별 FPY 추이 꺾은선(최근 30일)을 추가하고, 분포 막대 3개도 넣어줘: 모델별 수율 비교(가로 막대, Top 10 model_code), 라인별 생산 수량(막대: LINE_1~LINE_6), 스테이션별 평균 택트타임(막대: SMT/DISPENSE/REFLOW/ALIGN/AOI/FINAL).
```

**4단계 —** 운영 지표 3개 추가.

```
운영 지표 3개를 더 추가해줘: 라인×일 수율 히트맵(X축 날짜, Y축 라인, 색상 수율), 근무조(shift)별 수율 비교(막대: DAY/SWING/NIGHT), 고객(customer)별 생산 비중(도넛).
```

**5단계 —** 필터 추가.

```
마지막으로 필터를 추가해줘: 날짜 범위(기본 최근 30일), 라인(line_id), 모델(model_code), 근무조(shift).
```

### 생성 확인

```
방금 만든 "생산/수율 운영 대시보드"가 잘 생성됐는지 확인해줘. 대시보드 URL과 포함된 위젯 목록을 보여줘.
```

> ✅ 12개 위젯과 4개 필터가 보이면 정상입니다.

## Part B: 품질/불량 분석 대시보드

> 불량 파레토와 자재·공정 상관, AA(Active Alignment) 화질 지표를 다루는 품질 분석판.

### Genie Code 프롬프트

> 파레토부터 만들고 KPI·상관 분석·화질 위젯을 한 단계씩 덧붙입니다.

**1단계 —** 대시보드 뼈대 + 불량 파레토 2종.

```
gold.defect_pareto, gold.material_defect_correlation, gold.aa_quality_trend, gold.spc_process_capability 테이블로 "품질/불량 분석 대시보드"를 AI/BI 대시보드로 새로 만들어줘. 우선 불량 코드별 파레토(막대+누적선, defect_code 상위 15, 누적 % 라인)와 불량 카테고리 × severity 분포(Stacked Bar: PLACEMENT/BONDING/ALIGNMENT/CONTAMINATION/IMAGE_QUALITY × CRITICAL/MAJOR/MINOR)부터.
```

**2단계 —** 맨 위에 KPI 카운터 3개 추가.

```
맨 위에 KPI 카운터 3개를 추가해줘: 전체 불량률 %(게이지), CRITICAL 불량 건수(오늘), 평균 공정능력 Cpk(핵심 공정 평균).
```

**3단계 —** 상관 분석 위젯 3개 추가.

```
상관 분석 위젯 3개를 추가해줘: 자재 공급사별 불량률(가로 막대, supplier별 — Sup_S7/S8 부각 예상), 자재 로트↔불량 상관 상위(막대: @ccm_factory.gold.material_defect_correlation 상위 10), root_cause 분포(가로 막대: MATERIAL/EQUIPMENT/PROCESS/OPERATOR/ENVIRONMENT).
```

**4단계 —** AA 화질 & 공정능력 위젯 3개 추가.

```
AA 화질·공정능력 위젯 3개를 추가해줘: 모델별 MTF(center) 분포(박스플롯 또는 분포 막대, @ccm_factory.gold.aa_quality_trend), AA 틸트 산포 추이(일별 tilt 표준편차 꺾은선), 공정 파라미터별 Cpk 히트맵(X축 날짜, Y축 공정, 색상 Cpk — 1.33 미만 경고색).
```

**5단계 —** 필터 추가.

```
마지막으로 필터를 추가해줘: 날짜 범위, 라인, 모델, 불량 카테고리(defect_category).
```

### 생성 확인

```
"품질/불량 분석 대시보드"의 URL과 위젯 목록을 보여줘. Cpk 히트맵에서 1.33 미만 구간이 경고색으로 표시되는지 확인해줘.
```

> 💡 **Cpk 1.33**은 일반적인 공정능력 관리 기준선입니다. 미만 구간이 눈에 띄면 대시보드가 의도대로 만들어진 것입니다.

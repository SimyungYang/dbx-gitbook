## Part D: Lakebase 연동 — 에이전트 세션 관리 (선택)

> Lakebase 사용 가능한 환경에서만 진행합니다. 먼저 확인하세요:
> ```
> 내 환경에서 Lakebase(Databricks managed PostgreSQL)를 사용할 수 있는지 확인해줘.
> ```
> 사용 불가하면 이 Part를 건너뛰세요. 에이전트는 Lakebase 없이도 동작합니다.

### 개념

대화 이력을 Lakebase에 저장하면 컨텍스트 유지, 사용자별 선호 학습, 사용 패턴 분석이 가능합니다.

#### Genie Code 프롬프트 (AI Dev Kit MCP: manage_lakebase_database)

**1단계 —** 데이터베이스부터.

```
Lakebase 데이터베이스 ccm_agent_db 를 카탈로그 ccm_factory 에 만들어줘.
```

**2단계 —** 세션 테이블.

```
chat_sessions 테이블을 만들어줘:
- session_id UUID PRIMARY KEY
- user_name VARCHAR(100)
- line_context VARCHAR(20)   -- 관심 라인
- started_at TIMESTAMP DEFAULT NOW()
- ended_at TIMESTAMP
- total_messages INT DEFAULT 0
- satisfaction_score INT
```

**3단계 —** 메시지 테이블.

```
chat_messages 테이블을 추가해줘:
- message_id UUID PRIMARY KEY
- session_id UUID REFERENCES chat_sessions
- role VARCHAR(20)           -- 'user' or 'assistant'
- content TEXT
- agent_used VARCHAR(50)     -- 'ka', 'genie', 'supervisor'
- response_time_ms INT
- created_at TIMESTAMP DEFAULT NOW()
```

**4단계 —** 피드백 테이블.

```
agent_feedback 테이블을 추가해줘:
- feedback_id UUID PRIMARY KEY
- message_id UUID REFERENCES chat_messages
- is_helpful BOOLEAN
- feedback_text TEXT
- created_at TIMESTAMP DEFAULT NOW()
```

## Part E: 에이전트 고도화 팁

### 1. Knowledge Assistant 정확도 향상

| 방법 | 설명 | 효과 |
|------|------|------|
| **청킹 최적화** | content를 500자 단위 분할, 오버랩 100자 | 검색 정밀도 |
| **메타데이터 필터** | process_stage/category 사전 필터 | 불필요 문서 제외 |
| **Hybrid Search** | 키워드 + 벡터 결합 | 정확한 용어 매칭 + 의미 검색 |
| **리랭킹** | 상위 20개를 LLM으로 재정렬 | 최종 답변 품질 |

### 2. Genie Agent 정확도 향상

| 방법 | 설명 |
|------|------|
| **샘플 질문 추가** | 실패한 질문을 Genie Space 샘플로 등록 |
| **테이블 COMMENT 보강** | 컬럼 값 범위/단위 명시 |
| **General Instructions** | 제조 용어 사전(수율/FPY/OEE/Cpk 정의) |
| **Gold 단순화** | 복잡 조인을 사전 수행하여 SQL 복잡도 감소 |

### 3. Supervisor 라우팅 정확도 향상

| 방법 | 설명 |
|------|------|
| **의도 분류 예시 추가** | System Prompt에 더 많은 제조 도메인 예시 |
| **Fallback** | 라우팅 불확실 시 둘 다 호출 후 통합 |
| **피드백 루프** | agent_feedback 데이터로 지속 개선 |

### 4. MLflow로 품질 평가

```
"스마트팩토리 AI 어시스턴트"의 최근 대화들을 MLflow Tracing으로 확인하고,
라우팅 정확도와 응답 품질을 평가해줘. 개선이 필요한 질문 유형을 알려줘.
```

## Part F: 실전 데모 시나리오

교육 마무리 데모로 아래 대화를 시연합니다.

```
사용자: 최근 라인2에서 MTF 불량이 늘어난 것 같은데, 현황이 어때?

AI: 최근 7일간 라인2의 MTF 관련 품질을 분석한 결과입니다:
    - AA 공정 MTF 불량률: 6.8% (전주 대비 +2.3%p 증가)
    - 평균 MTF 중심값: 79.2 (전주 82.5에서 하락)
    - FAIL 집중 설비: EQ_L2_AA_02 (불량률 11.5%)
    - 특정 자재 로트(Sup_S7 렌즈)와 상관 관찰됨

사용자: 왜 늘었을까? 그리고 현장에 안내할 대응 방법은?

AI: [데이터 분석]
    EQ_L2_AA_02 설비에서 tilt_y 편차가 규격(±3 arcmin)을 초과하는 비율이 증가했습니다.
    같은 기간 Sup_S7 렌즈 로트 투입 비율이 높았습니다.

    [대응 가이드 — 제조 SOP]
    1. AA 장비 점검: tilt 캘리브레이션 재수행 (EQ_L2_AA_02)
    2. 자재 격리: Sup_S7 해당 로트 격리 후 수입검사 재확인
    3. MTF 규격 재판정: 경계 로트 샘플 재측정
    4. 8D 리포트 착수: root_cause = ALIGNMENT/MATERIAL 병행 조사

    🔍 관련 질문:
    - EQ_L2_AA_02의 최근 tilt 편차 추이를 볼 수 있나요?
    - Sup_S7 로트가 투입된 다른 라인도 영향이 있나요?
    - 이 설비의 최근 점검(PM) 이력은?
```

## 핵심 포인트 정리

| 배운 것 | Databricks 기능 | 비즈니스 가치 |
|---------|----------------|-------------|
| Knowledge Assistant | Vector Search, RAG | 24시간 제조 지식 셀프서비스, 매뉴얼 검색 자동화 |
| Genie Agent | Genie Space (NL2SQL) | 비개발자 셀프서비스 데이터 분석 |
| Supervisor Agent | Multi-Agent 오케스트레이션 | 단일 인터페이스로 분석+가이드 통합 |
| Lakebase 연동 | PostgreSQL OLTP | 대화 이력·피드백 저장 |
| 에이전트 평가 | MLflow on Databricks | 품질 모니터링·지속 개선 |

## 카탈로그 / 스키마 / 볼륨 생성

데이터를 저장하려면 먼저 상위 네임스페이스를 만들어야 합니다. Unity Catalog는 데이터를 **카탈로그 > 스키마 > 테이블/볼륨** 3단계로 계층화합니다.

- **카탈로그 (catalog)** — 최상위 네임스페이스. 데이터 격리와 거버넌스의 경계 단위 (여기서는 `ccm_factory`)
- **스키마 (schema)** — 카탈로그 하위의 논리적 그룹. 테이블·볼륨 등을 목적별로 묶습니다 (여기서는 `bronze`/`silver`/`gold`/`quarantine`)
- **테이블 (table)** — 스키마에 속한 정형 데이터 (행·열)
- **볼륨 (volume)** — 스키마에 속한 비정형 파일 저장 위치 (PDF·이미지·zip 등)

> 상위 객체가 있어야 하위 객체를 만들 수 있으므로 **카탈로그 → 스키마 → (테이블/볼륨)** 순서로 진행합니다. 아래에서 카탈로그·스키마·볼륨을 먼저 만든 뒤 [시드 데이터 다운로드 & 적재](00-seed-import#시드-데이터-다운로드--적재)에서 테이블을 채웁니다.

> 🚨 **공유 워크스페이스 — 카탈로그 이름은 반드시 본인 고유로!**
>
> - 여러 명이 한 워크스페이스를 쓰는 경우, 모두가 `ccm_factory`를 만들면 **두 번째 사람부터는 "이미 있으면 스킵"으로 넘어가 같은 카탈로그·테이블을 공유**하게 되어 서로의 데이터를 덮어씁니다.
> - 그래서 **본인 고유 카탈로그 `ccm_factory_<본인ID>`**(예: `ccm_factory_hong`)를 만드세요.
> - 이 가이드는 편의상 `ccm_factory`로 표기합니다 — 여러분은 **어디서든 이를 본인 카탈로그명으로 바꿔** 읽고 프롬프트하세요.
> - **권장(Vibe 방식)**: [Custom Instructions](00-custom-instructions#custom-instructions--genie-code의-시스템-프롬프트)에 `내 카탈로그는 ccm_factory_hong 이야`를 넣어두면, 이후 프롬프트에서 "내 카탈로그의 bronze에…"처럼 말해도 Genie Code가 본인 카탈로그를 자동으로 씁니다.
> - 각자 별도 워크스페이스/카탈로그를 배정받았다면 `ccm_factory` 그대로 써도 됩니다.

```
Unity Catalog에 다음 환경을 설정해줘 (기존 오브젝트가 있으면 DROP하지 말고 스킵):

- 카탈로그: ccm_factory_<본인ID>   (예: ccm_factory_hong — 공유 워크스페이스 충돌 방지)
- 스키마: bronze, silver, gold, quarantine
- 볼륨: bronze 스키마에 raw_files 볼륨 (PDF/이미지 등 비정형 저장용)

각 스키마에 COMMENT:
- bronze: 'Raw 제조/공정/검사/설비 텔레메트리'
- silver: '정제·표준화된 데이터'
- gold: '수율·불량·OEE 등 비즈니스 집계'
- quarantine: '데이터 품질 위반 격리'
```

### 확인

```
ccm_factory_<본인ID>의 모든 스키마와 COMMENT를 보여줘.
```

기대 결과:

| 스키마 | 설명 |
|--------|------|
| `bronze` | Raw 제조/공정/검사/설비 텔레메트리 |
| `silver` | 정제·표준화된 데이터 |
| `gold` | 수율·불량·OEE 등 비즈니스 집계 |
| `quarantine` | 데이터 품질 위반 격리 |

### ✅ Custom Instructions에 카탈로그 반영 확인

방금 만든 카탈로그명이 [Custom Instructions](00-custom-instructions#custom-instructions--genie-code의-시스템-프롬프트)에 등록돼 있어야, 이후 모든 모듈의 `ccm_factory.…` 프롬프트가 **자동으로 내 카탈로그를 가리킵니다**. 방금 만든 이름과 일치하는지 확인하고, 다르면 지금 업데이트하세요.

```
내 Custom Instructions를 확인해줘. '카탈로그' 규칙에 방금 만든 내 카탈로그명이 정확히 들어가 있는지 보고,
가이드의 ccm_factory를 내 카탈로그로 해석하라는 매핑 규칙, 접두어 없는 bronze/silver/gold/quarantine도 내 카탈로그로 해석하는 규칙, USE CATALOG 선행 규칙이 모두 있는지 점검해줘. 없거나 다르면 내 실제 카탈로그명으로 업데이트해줘.
```

> 💡 이 매핑 덕분에 이후 프롬프트는 가이드 그대로 `ccm_factory.bronze.…`로 붙여넣어도 Genie Code가 내 카탈로그(`ccm_factory_<본인ID>`)에서 실행합니다. (별도 워크스페이스면 이 단계는 건너뛰어도 됩니다.)

## Part B: 분포 탐색

숫자만 보지 말고 **분포의 모양**을 봅니다.

### 수율 / 판정 분포

```
카메라 모듈 최종 판정 현황을 분석해줘:
1. @ccm_factory.bronze.final_image_test.test_result (PASS/FAIL) 비율
2. @ccm_factory.bronze.active_alignment.aa_result (PASS/FAIL/RETRY) 비율
3. @ccm_factory.bronze.traceability.final_result (PASS/FAIL/REWORK) 비율
4. 라인(line_id)별, 모델(model_code)별 FAIL 비율 상위 10개
결과를 막대 차트로 시각화해줘.
```

### MTF(해상력) 분포 — 카메라 모듈의 핵심 품질지표

```
@ccm_factory.bronze.active_alignment의 mtf_center_pct 와 @ccm_factory.bronze.final_image_test의 mtf_sfr_center 분포를 히스토그램으로 보여줘.
- @ccm_factory.bronze.product_master의 spec_mtf_min 규격선을 기준으로, 규격 미달 비율도 계산
- module_type(AF/OIS/ToF)별로 MTF 분포가 어떻게 다른지 비교
- 규격을 넘는 이상치(mtf > 100 등)가 보이면 표시
```

> 💡 `active_alignment`·`final_image_test`에는 `model_code`가 없습니다 — `serial_id → @ccm_factory.bronze.traceability`로 `model_code`를 얻어 `@ccm_factory.bronze.product_master`(spec_mtf_min·module_type)에 조인하도록 함께 요청하세요.

> 💡 MTF(Modulation Transfer Function)는 렌즈-센서 정렬 품질을 나타내는 해상력 지표입니다. 중심(center)보다 코너(corner)가 낮은 것이 정상이며, 코너 MTF가 급락하면 틸트(tilt) 불량을 의심합니다.

### 설비/라인/모델 차원 분포

```
생산·불량을 여러 차원으로 쪼개서 보여줘:
1. 라인(line_id)별 생산량(@ccm_factory.bronze.traceability 기준)과 불량률
2. 설비 유형(equipment_type)별 처리 건수 (@ccm_factory.bronze.production_events 조인)
3. 모델(model_code)별·고객(customer)별 생산 비중 (도넛 차트)
4. 근무조(shift)별 불량률 비교 (DAY/SWING/NIGHT)
시각화도 함께 만들어줘.
```

> 💡 `traceability`·`production_events`에는 `line_id`가 없습니다 — `wo_id → @ccm_factory.bronze.work_orders`로 `line_id`를 가져와 조인하세요(라인 차원 집계 시).
